# Daty po Polsku | Polish Dates (Który vs Kiedy) Practice

A premium, responsive, glassmorphic Single Page Application designed to help language learners master Polish calendar dates listening practice and grammatical declensions.

## 🌐 Live Demo
Play it live here: [https://ippikin.github.io/polish-dates-practice/](https://ippikin.github.io/polish-dates-practice/)

---

## 🚀 Key Features

* **Grammar Mastery: Który dziś jest? vs. Kiedy?**:
  * **Który dziś jest? (Mianownik / Nominative)**: Day ends in `-y` / `-i` (*pierwszy, drugi, dwudziesty piąty*) + month in genitive (*marca, września*).
  * **Kiedy? (Dopełniacz / Genitive)**: Day ends in `-ego` (*pierwszego, drugiego, dwudziestego piątego*) + month in genitive.
  * **Date Ranges (Od... do...)**: Spans like *od drugiego do dziewiątego marca*.
  * **Grammar Challenge Mode**: Context sentences where learners choose between `-y/-i` and `-ego`.
* **Speech Synthesis Control**: 
  * Play buttons trigger the browser's native Web Speech synthesis (`pl-PL`).
  * Features a **slow speech speed toggle (0.55x)** to assist with fast Polish pronunciation and complex consonant clusters.
  * Voice selector dropdown allows switching between available system voices.
* **Interactive Feedback & Session History**:
  * Instant feedback with full written Polish spelling and grammatical explanations.
  * Session history with one-click replay audio buttons.
  * LocalStorage saves statistics and history automatically.
